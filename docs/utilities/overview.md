# Utilities Overview

The utils module provides general-purpose utilities and helper functions used throughout pydelling.

## Available Utilities

### Geometry Operations
- Spatial calculations and transformations
- Coordinate system conversions
- Geometric analysis tools

### General Utilities
- File handling helpers
- Data validation functions
- Common mathematical operations
