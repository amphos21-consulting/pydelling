# Interpolation Overview

The interpolation module provides tools for spatial interpolation and estimation methods commonly used in numerical modeling workflows.

## Available Tools

### Sparse Interpolation
- Efficient interpolation methods for large datasets
- Support for various interpolation kernels
- Memory-optimized algorithms

### KDE Estimator
- Kernel Density Estimation for spatial data
- Bandwidth selection methods
- Multi-dimensional support
