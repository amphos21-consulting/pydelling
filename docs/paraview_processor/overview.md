# ParaView Integration Overview

The paraview_processor module provides tools for automated ParaView processing and visualization workflows.

## Available Filters

### Data Processing Filters
- AppendArcLength: Add arc length data to streamlines
- Calculator: Perform mathematical operations on fields
- CellDataToPointData: Convert cell-centered to point data
- Clip: Extract portions of datasets
- StreamTracer: Generate streamlines from vector fields
